# Daniel Mwasanguti — Personal Ministry Website

A premium, minimal, responsive static website concept for a personal ministry profile connected with The LIFE Ministry Tanzania (LMT).

## Project structure

```text
daniel_ministry_website/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── main.js
└── src/
    └── image/
        ├── hero-ministry.jpg       (add your own image)
        ├── about-daniel.jpg        (add your own image)
        └── story-jesus-film.jpg    (add your own image)
```

## Preview locally

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, open a terminal in the project folder and run:
   `python3 -m http.server 8000`
4. Visit `http://localhost:8000`.

No build step or framework is required.

## Before publishing — important edits

- Public contact email: `daniel.mwasanguti@lmtanzania.org`.
- Add genuine, high-quality photographs in `src/image/` using the exact filenames above. Use photos you have permission to publish.
- Replace the sample Jesus Film story with a verified testimony and get consent before sharing names, faces, or sensitive details.
- Verify the ministry impact numbers, time period, and what each number means before publishing.
- Review the wording about LMT and ensure it accurately reflects your role and is consistent with ministry communication guidelines.
- Add your preferred social links if you want them displayed.
- Consider adding a privacy notice if you later add forms, analytics, or mailing-list signup.

## Google Sites note

This is a standalone HTML/CSS/JS website package, not a Google Sites import file. Google Sites does not directly import a complete HTML project as a native editable site. You can use this as a design and copy reference when recreating the pages in Google Sites, or host the static site on a suitable web host.

## Design direction

Jesus Film Project-inspired red, charcoal, and white palette; restrained typography, generous spacing, fine rules, editorial layouts, minimal cards, accessible navigation, and mobile responsiveness.
